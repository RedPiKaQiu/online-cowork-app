## Why

阶段 1 已提供持久化项目数据，但没有受保护的入口来创建、修改或删除项目。需要一个单管理员后台来管理项目生命周期，并安全生成可交给协作者的匿名项目链接。

## What Changes

- 添加仅支持单管理员的登录、登出和会话保护机制。
- 添加管理员项目列表、创建、编辑、软删除和恢复项目链接的后台页面及服务端接口。
- 为新建项目及重置链接生成高熵访问令牌；系统仅持久化令牌哈希，原始链接仅在创建或重置时返回给管理员。
- 将未登录访问 `/admin` 及管理员 API 的请求重定向或拒绝。

## Capabilities

### New Capabilities

- `administrator-authentication`: 单管理员的凭据验证、会话建立、登出及后台访问保护。
- `administrator-project-management`: 管理员对项目的创建、编辑、软删除及匿名访问链接生成和重置。

### Modified Capabilities

- 无。

## Impact

- 新增登录页、管理员后台路由、鉴权工具、管理员 API 和项目管理 UI。
- 新增管理员凭据、会话密钥及应用基地址环境变量。
- 使用现有 `projects.access_token_hash` 字段，并增加安全令牌生成与哈希模块。
- 现有首页看板暂不改为通过匿名项目链接读取；该能力留给后续阶段。
