## MODIFIED Requirements

### Requirement: 任务状态与排序持久化
系统 SHALL 持久化任务标题、说明、所属项目、状态、列内排序位置、负责人、版本号及时间戳。任务状态 MUST 为 `box`、`todo` 或 `done` 之一。读取有效项目的看板快照时，系统 MUST 仅返回该项目的任务，并按状态和列内排序位置恢复看板顺序。

#### Scenario: 读取项目看板任务
- **WHEN** 系统读取一个有效项目的任务
- **THEN** 系统按任务状态和列内排序位置返回该项目的全部未删除任务

#### Scenario: 将任务移入事项盒子
- **WHEN** 任务状态被更新为 `box`
- **THEN** 系统保存该状态并清除任务负责人
