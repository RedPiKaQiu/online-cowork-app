## MODIFIED Requirements

### Requirement: 任务状态与排序持久化
系统 SHALL 持久化任务标题、说明、所属项目、状态、列内排序位置、负责人、完成时间、版本号及时间戳。任务状态 MUST 为 `box`、`todo` 或 `done` 之一。完成时间仅表示任务最近一次进入 `done` 状态的时刻；任务进入 `done` 时系统 MUST 写入当前完成时间，离开 `done` 时 MUST 清空完成时间，再次进入 `done` 时 MUST 覆盖为新的完成时间。读取有效项目的看板快照时，系统 MUST 仅返回该项目的任务，并按状态及对应展示规则恢复看板顺序。

#### Scenario: 读取项目看板任务
- **WHEN** 系统读取一个有效项目的任务
- **THEN** 系统按任务状态及该状态的展示排序返回该项目的全部未删除任务

#### Scenario: 将任务移入事项盒子
- **WHEN** 任务状态被更新为 `box`
- **THEN** 系统保存该状态、清除任务负责人及完成时间

#### Scenario: 完成任务
- **WHEN** 任务从 `box` 或 `todo` 进入 `done`
- **THEN** 系统持久化该状态并记录该次完成的完成时间

#### Scenario: 重新完成任务
- **WHEN** 已恢复至非 `done` 状态的任务再次进入 `done`
- **THEN** 系统以本次进入 `done` 的时间覆盖此前完成时间
