# project-link-access Specification

## Purpose

让持有不可预测访问链接的项目协作者能够安全加载该项目的完整看板，且不会得到其他项目或内部访问凭据的数据。

## Requirements

### Requirement: 通过有效访问令牌读取项目快照
系统 SHALL 接受项目访问令牌并返回该活动项目的项目元数据、成员和任务快照。响应 MUST 仅包含该项目的数据，且项目元数据不得包含访问令牌哈希或其他内部凭据字段。

#### Scenario: 加载有效项目链接
- **WHEN** 协作者使用当前有效的项目访问令牌请求项目页面或快照
- **THEN** 系统返回该项目的 ID、名称、描述、版本、成员和按状态分组的任务

#### Scenario: 令牌无法读取其他项目数据
- **WHEN** 协作者使用一个有效项目的访问令牌请求快照
- **THEN** 系统不会返回任何其他项目的成员或任务

### Requirement: 任务快照保持看板顺序
系统 SHALL 将任务按 `box`、`todo`、`done` 三个状态分组。`box` 与 `todo` 组 MUST 按持久化位置升序返回；`done` 组 MUST 按完成时间降序返回，完成时间相同的事项再按稳定的持久化位置升序返回。

#### Scenario: 读取已排序任务
- **WHEN** 项目中同一状态有多个任务
- **THEN** `box` 与 `todo` 状态任务按列内位置从小到大排列，`done` 状态任务按完成时间从新到旧排列

#### Scenario: 同时完成的事项
- **WHEN** 多个已完成事项具有相同完成时间
- **THEN** 快照以其持久化位置升序提供稳定顺序

### Requirement: 失效链接得到统一的不可用结果
系统 SHALL 将未知、已重置或已删除项目的访问令牌视为不存在，而不泄露其失效原因或项目状态。

#### Scenario: 访问无效或已重置链接
- **WHEN** 协作者打开未知或已经重置的项目访问令牌
- **THEN** 页面显示“项目不存在或链接已失效”，快照接口返回不存在结果

#### Scenario: 访问已删除项目链接
- **WHEN** 协作者打开属于软删除项目的访问令牌
- **THEN** 页面显示“项目不存在或链接已失效”，且不返回项目数据
